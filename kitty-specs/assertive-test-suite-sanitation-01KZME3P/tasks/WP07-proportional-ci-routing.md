# WP07 — Proportional CI Route Ownership

## Do First

Load `ci-cd-carl`. Read accepted red-main ADR, `.github/workflows/ci-quality.yml` regression/quarantine/quality-gate blocks, route contract/data model, WP01 frozen workload, and approved node sets from WP03–WP06. Claim WP07 canonically.

## Objective

Stop paying whole-tree collection for stable narrow classes. Each changed narrow class gets one owner selector and documented coverage/platform/hard-gate overlap. Preserve accepted P0 blocking-red authority and keep quarantine non-blocking/environment-only.

## T039 — Explicit Narrow Selectors

- Baseline regression job runs `pytest tests/ -m regression`; only the final approved regression owner set should collect.
- Replace whole-tree discovery with explicit owned paths or a stable manifest reflected directly in workflow. Do not create a second dynamic selector mechanism.
- Do likewise for quarantine only if the approved set is stable and nonempty/empty semantics are explicit.
- Preserve exit code handling: empty class may be green only when owner manifest is actually empty. Regression known red remains blocking under current ADR.

## T040 — Route Roles and Mapping

- Produce manifest entries with route ID, role (`owner`, `coverage`, `platform`, `hard_gate`), required flag, event set, exact selector, environment ID, and base→HEAD mapping.
- Require exactly one owner for changed narrow classes. Secondary execution is allowed and expected where documented.
- Include route DAG edges for install, shard, quality-gate/release authority so critical path is computable.
- Deleted/renamed routes stay mapped in performance denominator.

## T041 — Architectural Contracts

- Update existing owned architecture tests; do not add redundant new test files.
- `test_ci_quality_path_filters.py`: validate exact manifest/selector without recursively collecting the entire suite inside a 240-second test. Use static workflow parsing plus bounded owned-path collection.
- `test_marker_job_completeness.py`: distinguish owner vs secondary routes.
- `test_quarantine_marker.py`: preserve Tier-3-only, non-blocking semantics; no test-specific exception for #2342.
- `test_suite_jobs_gate_blocking.py`: preserve red-main regression blocking contract and release authority. No governance reversal.

## T042 — Selection and Timing Proof

- Collect each HEAD selector and compare exact expected node set from approved shards/census.
- Prove no retained expected node is unrouted and no narrow class has duplicate owner.
- Run frozen base and HEAD route workloads three equivalent cold repetitions with same runner, workers, cache/install/env.
- Report median/max, summed compute, and DAG critical path. Attribute deletion, routing, and bootstrap effects separately.
- Whole-tree collection comparison uses the frozen command, not a post-change subset.

## T043 — Evidence/Validation

- Route evidence profile records selectors, roles, nodes, raw hashes, workload mapping, and timings.
- Run owned architecture tests and workflow YAML validation.
- Use local action/syntax validation available in repo; do not push to test CI prematurely.
- `ruff` Python changes; commit workflow/tests/evidence.

## Definition of Done

- [ ] Regression/quarantine narrow routes no longer collect unrelated whole tree where manifest is stable.
- [ ] Exactly one owner plus explicit secondary roles per changed class.
- [ ] #2782 owner stays blocking red; quarantine stays non-blocking Tier-3 only.
- [ ] Static/bounded route tests replace 240-second recursive collection probe.
- [ ] Three-run fixed workload comparison records compute and critical path.

## Reviewer Guidance

Recompute selector node sets from workflow. Reject route deletion from denominator, `tests/ -m ...` under a different spelling, an accidental quality-gate policy change, or tests that only search workflow strings without validating selection.
